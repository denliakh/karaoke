    Автотюн

    30–50% — естественно подправляет. 100% — эффект «робота», как у рэперов.
    Если знаете тональность песни — выберите её, звучит точнее. Не знаете — оставьте «Все ноты».
    Чтобы голос звучал вместе с музыкой, выключите Direct Monitor на аудиокарте.

    Ключ YouTube

    Нужен один раз, чтобы программа могла искать песни. Бесплатно.
    1. Откройте console.cloud.google.com → YouTube Data API v3 (выберите или создайте проект) и нажмите Enable.
    2. Зайдите в APIs & Services → Credentials → Create credentials → API key (или возьмите существующий ключ этого проекта).
    3. Вставьте ключ ниже (он начинается с AIza).
