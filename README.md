# 🎤 Караоке

Домашнее караоке в браузере: поиск только караоке-версий на YouTube, очередь песен, эффекты голоса (эхо, зал, эквалайзер, авто-громкость), автотюн и дуэт на два микрофона.

Открыть: https://denliakh.github.io/karaoke/

Для поиска нужен свой бесплатный ключ YouTube Data API v3 — программа попросит его при первом запуске и хранит только в браузере.
